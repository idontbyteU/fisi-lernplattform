🧩 Parameterbindung (Platzhalter ?)
sql = "INSERT INTO tblArtikel (Name, Anzahl) VALUES (?,?)"
cursor.execute(sql, [n, a])
📌
Vorteile der Parameterbindung: einfacher & lesbarer · Schutz vor SQL-Injection · korrekte Typuebergabe · bessere Performance bei Massenoperationen.
⭕ NULL / None

NULL aus der Datenbank wird in Python zu None. None geht nicht direkt in einen f-String – vorher in einen Leerstring umwandeln. Ein Datensatz ist oft ein Tupel (unveraenderbar), daher erst in eine Liste wandeln:

daten = cursor.fetchall()
for ds in daten:
    ds = list(ds)
    if ds[2] is None: ds[2] = ""
    print(f"{ds[0]:5} {ds[2]:10}")
🕒 Modul datetime (Datum & Zeit)
import datetime

zeit  = datetime.time(13, 34, 22)              # Uhrzeit
datum = datetime.date(1912, 6, 23)             # Datum
mond  = datetime.datetime(1969, 7, 21, 3, 56)  # Datum + Zeit
jetzt = datetime.datetime.now()

diff  = ziel - jetzt   # Subtraktion zweier datetime -> timedelta
  • Objekte: date / time / datetime; timedelta fuer Differenzen
  • Zeitbereich: 01.01.0001 – 31.12.9999
📌
Kurz gemerkt: Verbindung → Cursor → execute(). Zum Schreiben immer commit(), zum Lesen gern fetchall(). Werte immer ueber Platzhalter (?) uebergeben – nie per String-Zusammenbau.
