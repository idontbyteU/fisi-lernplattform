LF 5SQL-Uebungen

SQLite3 mit Python · Aufgabe zuerst, Loesung aufklappen

Elf Uebungen zum Datenbankzugriff mit SQLite3. Erst selbst versuchen, dann die Loesung aufklappen. Die Grundlagen dazu stehen in der SQL-Referenz.

→ Basics → Grundlagen → CRUD → Spezial

UE 1 SQLite-Verbindung + Tabelle anlegen

Aufgabe: Verbinde dich mit lager.sqlite3 und lege die Tabelle tblArtikel an (id INTEGER PRIMARY KEY AUTOINCREMENT, Name TEXT, Anzahl INTEGER, Preis REAL).

// LOESUNG 
import sqlite3

db = sqlite3.connect("lager.sqlite3")
cursor = db.cursor()
cursor.execute("CREATE TABLE tblArtikel(id INTEGER PRIMARY KEY AUTOINCREMENT, Name TEXT, Anzahl INTEGER, Preis REAL)")
db.close()

UE 2 Datensatz einfuegen (mit commit)

Aufgabe: Fuege den Artikel 'Hut', Anzahl 14 ein. Denk an commit().

// LOESUNG 
db = sqlite3.connect("lager.sqlite3")
cursor = db.cursor()
cursor.execute("INSERT INTO tblArtikel (Name, Anzahl) VALUES('Hut',14)")
db.commit()
db.close()

UE 3 Alle Datensaetze auslesen (fetchall)

Aufgabe: Lies alle Artikel in eine Liste und gib sie formatiert aus.

// LOESUNG 
db = sqlite3.connect("lager.sqlite3")
cursor = db.cursor()
cursor.execute("SELECT * FROM tblArtikel")
data = cursor.fetchall()
db.close()

for ds in data:
    print(f"{ds[0]:4} {ds[1]:12} {ds[2]:5}")

UE 4 Parametrisiertes INSERT (Eingaben)

Aufgabe: Frage Name + Anzahl per input() ab und fuege sie SQL-injection-sicher mit Platzhaltern ein.

// LOESUNG 
n = input("Name: ")
a = int(input("Anzahl: "))

db = sqlite3.connect("lager.sqlite3")
cursor = db.cursor()
cursor.execute("INSERT INTO tblArtikel (Name, Anzahl) VALUES (?,?)", [n, a])
db.commit()
db.close()

UE 5 UPDATE mit WHERE

Aufgabe: Setze die Anzahl von 'Hut' auf 20.

// LOESUNG 
db = sqlite3.connect("lager.sqlite3")
cursor = db.cursor()
cursor.execute("UPDATE tblArtikel SET Anzahl=? WHERE Name=?", [20, "Hut"])
db.commit()
db.close()

UE 6 DELETE mit WHERE

Aufgabe: Loesche alle Artikel mit Anzahl 0.

// LOESUNG 
db = sqlite3.connect("lager.sqlite3")
cursor = db.cursor()
cursor.execute("DELETE FROM tblArtikel WHERE Anzahl=?", [0])
db.commit()
db.close()

UE 7 NULL / None behandeln

Aufgabe: Lies alle Artikel; wo Preis NULL ist, gib statt None einen Leerstring aus.

// LOESUNG 
db = sqlite3.connect("lager.sqlite3")
cursor = db.cursor()
cursor.execute("SELECT id, Name, Preis FROM tblArtikel")
daten = cursor.fetchall()
db.close()

for ds in daten:
    ds = list(ds)
    if ds[2] is None: ds[2] = ""
    print(f"{ds[0]:4} {ds[1]:12} {ds[2]}")

UE 8 Telefon-DB anlegen (Reset-Skript)

Aufgabe: Skript telefon1.py: loescht telefon.db falls vorhanden (try/except FileNotFoundError), legt sie neu an mit Tabelle telefon (ID INTEGER PRIMARY KEY AUTOINCREMENT, Name TEXT NOT NULL, Telefonnummer TEXT).

// LOESUNG 
import sqlite3, os

try:
    os.remove("telefon.db")
except FileNotFoundError:
    print("telefon.db nicht vorhanden")

db = sqlite3.connect("telefon.db")
cursor = db.cursor()
sql = """CREATE TABLE IF NOT EXISTS telefon (
    ID INTEGER PRIMARY KEY AUTOINCREMENT,
    Name TEXT NOT NULL,
    Telefonnummer TEXT)"""
cursor.execute(sql)
db.close()
print("Datenbank und Tabelle angelegt!")

UE 9 Eintraege erfassen in Endlosschleife

Aufgabe: telefon2.py: In einer Endlosschleife Name + Telefonnummer einlesen und per parametrisiertem INSERT speichern. Ein leerer Name beendet die Schleife. Nicht vergessen: commit()!

// LOESUNG 
import sqlite3

db = sqlite3.connect("telefon.db")
cursor = db.cursor()

while True:
    n = input("Name> ")
    if n == "": break
    t = input("Telefonnummer> ")
    sql = "INSERT INTO telefon (Name, Telefonnummer) VALUES (?,?)"
    cursor.execute(sql, [n, t])
    db.commit()
    print("Daten eingefuegt")

db.close()
print("Programm beendet")

UE 10 Formatierte Ausgabe sortiert nach Name

Aufgabe: telefon3.py: Alle Datensaetze sortiert nach Name als Tabelle mit Ueberschrift ausgeben, Spalten per f-String ausgerichtet.

// LOESUNG 
import sqlite3

db = sqlite3.connect("telefon.db")
cursor = db.cursor()
cursor.execute("SELECT * FROM telefon ORDER BY Name")

print("\nID Name             Telefonnummer")
print("----------------------------------")
for ds in cursor:
    print(f"{ds[0]:2} {ds[1]:16} {ds[2]}")

db.close()

UE 11 Datensatz per ID loeschen

Aufgabe: telefon4.py: Erst die Tabelle wie in UE 10 anzeigen, dann eine ID erfragen und den Datensatz loeschen (DELETE FROM telefon WHERE ID=?). commit() nicht vergessen!

// LOESUNG 
import sqlite3

db = sqlite3.connect("telefon.db")
cursor = db.cursor()
cursor.execute("SELECT * FROM telefon ORDER BY Name")

print("\nID Name             Telefonnummer")
print("----------------------------------")
for ds in cursor:
    print(f"{ds[0]:2} {ds[1]:16} {ds[2]}")

e = int(input("Welche ID loeschen> "))
cursor.execute("DELETE FROM telefon WHERE ID=?", [e])
db.commit()
db.close()
📌
Faustregeln: Schreiben (INSERT/UPDATE/DELETE) braucht commit() · Werte immer ueber Platzhalter (?) · zum Lesen fetchall(), dann DB schliessen.
