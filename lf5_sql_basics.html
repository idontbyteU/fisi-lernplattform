LF 5SQL-Basics erklärt — SQLite3 mit Python für Einsteiger

Der komplette Ablauf einmal von vorn — jede Zeile erklärt

Diese Seite geht das eine Komplettbeispiel Zeile für Zeile durch: von der Verbindung über Tabelle anlegen, Daten schreiben und lesen bis zum Schliessen. Ideal zum ersten Verstehen, bevor du zur kompakten SQL-Referenz greifst.

→ Zur SQL-Referenz
🧩 Das Komplettbeispiel

Ein durchgehendes Skript — alle folgenden Abschnitte erklären die einzelnen Bausteine daraus:

import sqlite3
# 1. Verbindung und Cursor erstellen
db = sqlite3.connect("schule.db")
cursor = db.cursor()
# 2. Tabelle anlegen
sql_create = """CREATE TABLE schueler (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    alterj INTEGER,
    klasse TEXT
)"""
cursor.execute(sql_create)
# 3. Daten eintragen (und speichern!)
cursor.execute("INSERT INTO schueler (name, alterj, klasse) VALUES ('Anna', 27, 'FI2027')")
cursor.execute("INSERT INTO schueler (name, alterj, klasse) VALUES ('Hans', 22, 'FI2027')")
db.commit()
# 4. Daten abfragen und formatiert ausgeben
cursor.execute("SELECT * FROM schueler WHERE id < 5 ORDER BY id DESC")
for ds in cursor:
    print(f"{ds[0]:2} {ds[1]:6} {ds[2]:3} {ds[3]:8}")
# 5. Verbindung schliessen
db.close()
🐍 Allgemeine Python-Syntax

import sqlite3 — damit holst du dir den Werkzeugkasten für Datenbanken in dein Skript. Ohne diese Zeile kennt Python die Datenbank-Befehle nicht.

Variablen wie db, cursor, sql_create oder ds sind selbst gewählte Namen — du könntest sie auch anders nennen. Sie sind nur Behälter, in denen du dir die Verbindung, den Cursor, einen SQL-Text oder eine Ergebniszeile merkst.

Strings & Anführungszeichen: Text steht in Anführungszeichen. Kurzes, einzeiliges in "..."; für lange, mehrzeilige SQL-Befehle nimmst du dreifache Anführungszeichen """...""" — so darf der Text über mehrere Zeilen gehen (siehe sql_create).

🗄️ Die Datenbank-Befehle (sqlite3-Modul)

connect("schule.db") — öffnet die Datenbankdatei. Existiert sie nicht, wird sie bei Bedarf automatisch erstellt.

db.cursor() — liefert den Cursor. Bild dazu: db ist die Telefonleitung zur Datenbank, der cursor ist die Person, der du am anderen Ende deine Befehle diktierst.

cursor.execute(...) — führt einen SQL-Text aus (Tabelle anlegen, einfügen, abfragen …).

db.commit() — Änderungen liegen zunächst nur im Zwischenspeicher (in der laufenden Transaktion). Erst commit() schreibt sie dauerhaft auf die Platte.

db.close() — gibt die Datei wieder frei. Gehört zum sauberen Programmieren dazu.

Achtung: commit() vergessen = Skript läuft fehlerfrei durch, aber nach close() ist nichts gespeichert.
Merke: Daten ändern (INSERT/UPDATE/DELETE) → committen. Nur lesen (SELECT) → kein commit nötig. CREATE speichert SQLite sofort.
📝 Die SQL-Sprache

CREATE TABLE — legt eine Tabelle an (stell sie dir wie ein Excel-Blatt vor) und definiert deren Spalten.

Datentypen: INTEGER für ganze Zahlen, TEXT für Zeichenketten — sie legen fest, was in eine Spalte darf.

PRIMARY KEY AUTOINCREMENT — wie eine Personalnummer: die Datenbank zählt selbst hoch und vergibt eine eindeutige id. Deshalb gibst du die id beim INSERT nie selbst an.

NOT NULL — macht die Spalte zum Pflichtfeld (darf nicht leer bleiben).

INSERT INTO ... VALUES — fügt eine Zeile ein. Spalten und Werte in gleicher Reihenfolge. Text steht in 'einfachen Anführungszeichen', Zahlen ohne.

SELECT * — der Stern bedeutet alle Spalten.

WHERE — filtert die Zeilen (nur die, die zur Bedingung passen).

ORDER BY ... DESC — sortiert absteigend; ohne DESC wird aufsteigend sortiert.

Achtung: Die Spalte heißt alterj, nicht alter — alter ist ein reserviertes SQL-Schlüsselwort (ALTER TABLE).
🔁 Ergebnisse verarbeiten (for-Schleife)

for ds in cursor: — holt jede Ergebniszeile einzeln ab und legt sie in ds.

Ein Datensatz ist ein Tupel, z. B. (1, 'Anna', 27, 'FI2027'). Der Index startet bei 0: ds[0]=id, ds[1]=name, ds[2]=alterj, ds[3]=klasse.

f-Strings setzen Variablen direkt in geschweifte Klammern {} ein. Die Formatbreite wie {ds[0]:2} reserviert mindestens 2 Zeichen Platz — so stehen die Spalten in der Konsole gerade untereinander.

Merke: SELECT liefert Tupel — Zugriff per Index, Zählung startet bei 0.
🧠 Teste dich
Was passiert, wenn du db.commit() nach einem INSERT weglässt?
Die Änderungen bleiben in der Transaktion (Zwischenspeicher) und gehen mit close() verloren — es wird nichts dauerhaft gespeichert.
Was steht in ds[2] beim Datensatz (1, 'Anna', 27, 'FI2027')?
27 — die Zählung beginnt bei 0, also ist ds[2] das dritte Element (alterj).
Warum heißt die Spalte alterj und nicht alter?
alter ist ein reserviertes SQL-Schlüsselwort (ALTER TABLE) — als Spaltenname würde es zu Problemen führen.
