🧾 Ueberblick: die wichtigsten SQL-Statements

SQL (Structured Query Language) ist die Sprache, um relationale Datenbanken abzufragen und zu veraendern. Die zentralen Befehle:

SELECT
Daten aus einer Tabelle auslesen (abfragen).
INSERT INTO … VALUES
Neue Datensaetze einfuegen.
DELETE FROM … WHERE
Datensaetze loeschen.
UPDATE … SET … WHERE
Bestehende Datensaetze aendern.
CREATE TABLE
Eine Tabelle erzeugen.
ALTER TABLE
Den Aufbau einer Tabelle aendern.
DROP TABLE
Eine Tabelle loeschen.
CREATE / DROP DATABASE
Eine Datenbank erzeugen / loeschen (nicht bei SQLite).
PRAGMA
Datenbank-Einstellungen setzen/abfragen (SQLite-spezifisch).
🐍 SQL-Datenbanken mit Python

Python kann viele relationale Datenbanken nutzen: MySQL, MariaDB, SQLite3, MS-SQL, Oracle, PostgreSQL, Access und weitere. Damit ist moeglich:

  • Tabellen & Spalten anlegen (CREATE, ALTER)
  • Datensaetze einfuegen / aendern / loeschen (INSERT / UPDATE / DELETE)
  • Daten abfragen (SELECT)

SQLite3 ist bereits in Python enthalten; andere Datenbanken brauchen ein nachinstalliertes Modul.

⚠️
Achtung Namenskollision: Nenne dein Skript nicht sqlite3.py oder mariadb.py – sonst importiert Python deine eigene Datei statt des Datenbank-Moduls.

⚖️ SQLite3 vs. MariaDB / MySQL

SQLite3

  • Kommunikation ueber das Dateisystem (lokal, performant)
  • Kein Serverdienst noetig
  • Pro Datei eine Datenbank
  • Ideal, wenn App + DB auf einem Rechner laufen
  • Fuer kleine/mittlere Last, kleiner Speicherbedarf
  • Transaktionsfaehig
  • Einige SQL-Funktionen fehlen

MariaDB / MySQL

  • Server notwendig
  • Ueber das Netzwerk erreichbar
  • Fuer viele parallele Zugriffe
  • Groesserer Funktionsumfang
🛠️ SQLite3-Zugriff vorbereiten

Verbindung aufbauen, Cursor holen und eine Tabelle anlegen:

import sqlite3

db = sqlite3.connect("datenbank.sqlite3")   # Datei-DB (wird bei Bedarf angelegt)
db = sqlite3.connect(":memory:")            # DB im RAM, nicht persistent

cursor = db.cursor()
sql = "CREATE TABLE tblArtikel(id INTEGER PRIMARY KEY AUTOINCREMENT, Name TEXT, Anzahl INTEGER, Preis REAL)"
cursor.execute(sql)
db.close()
💡
Tipp: Der grafische SQLite-Editor sqlitebrowser.org hilft beim einfachen Anlegen und Ansehen von Tabellen.
✏️ Schreiben: INSERT / UPDATE / DELETE + commit()
import sqlite3

db = sqlite3.connect("datenbank.sqlite")
cursor = db.cursor()
sql = "INSERT INTO tblArtikel (Name, Anzahl) VALUES('Hut',14)"
cursor.execute(sql)
db.commit()   # Bestaetigt die Speicherung!
db.close()
⚠️
Merkregel: Fuer INSERT, UPDATE und DELETE ist commit() notwendig – sonst werden die Daten NICHT gespeichert.
📖 Lesen: SELECT
cursor = db.cursor()
cursor.execute("SELECT * FROM tblArtikel")
for ds in cursor:
    print(f"{ds[0]:4} {ds[1]:12} {ds[2]:5}")
💡
Hinweis: SELECT * FROM sqlite_master liefert das Schema der Datenbank (welche Tabellen es gibt).
📥 fetchall() – Ergebnis in eigene Liste
cursor.execute("SELECT * FROM tblArtikel")
data = cursor.fetchall()   # ganzes Ergebnis in Variable
db.close()                 # DB kann sofort geschlossen werden

for ds in data:
    print(f"{ds[0]:4} {ds[1]:12} {ds[2]:8.2f}")

Vorteil: Die Datenbank ist sofort schliessbar und der Fehler Unread result found wird vermieden.

🎯 Der Datenbank-Cursor (kurz erklaert)

Erst die Verbindung (Connection) ueber connect(), dann den Cursor ueber db.cursor(). Der Cursor sendet SQL (execute) und nimmt Ergebnisse entgegen.

  • Ergebnis durchlaufen mit for ds in cursor: oder – besser – data = cursor.fetchall()
  • cursor.rowcount = Anzahl betroffener Datensaetze (bei SELECT in SQLite3 nicht verfuegbar)
🧩 Parameterbindung (Platzhalter ?)
sql = "INSERT INTO tblArtikel (Name, Anzahl) VALUES (?,?)"
cursor.execute(sql, [n, a])
📌
Vorteile der Parameterbindung: einfacher & lesbarer · Schutz vor SQL-Injection · korrekte Typuebergabe · bessere Performance bei Massenoperationen.
⭕ NULL / None

NULL aus der Datenbank wird in Python zu None. None geht nicht direkt in einen f-String – vorher in einen Leerstring umwandeln. Ein Datensatz ist oft ein Tupel (unveraenderbar), daher erst in eine Liste wandeln:

daten = cursor.fetchall()
for ds in daten:
    ds = list(ds)
    if ds[2] is None: ds[2] = ""
    print(f"{ds[0]:5} {ds[2]:10}")
🕒 Modul datetime (Datum & Zeit)
import datetime

zeit  = datetime.time(13, 34, 22)              # Uhrzeit
datum = datetime.date(1912, 6, 23)             # Datum
mond  = datetime.datetime(1969, 7, 21, 3, 56)  # Datum + Zeit
jetzt = datetime.datetime.now()

diff  = ziel - jetzt   # Subtraktion zweier datetime -> timedelta
  • Objekte: date / time / datetime; timedelta fuer Differenzen
  • Zeitbereich: 01.01.0001 – 31.12.9999
📌
Kurz gemerkt: Verbindung → Cursor → execute(). Zum Schreiben immer commit(), zum Lesen gern fetchall(). Werte immer ueber Platzhalter (?) uebergeben – nie per String-Zusammenbau.
