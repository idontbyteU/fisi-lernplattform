INSERT/UPDATE/DELETE, SELECT, fetchall & Cursor

Teil 2 von 3: Daten schreiben mit commit(), Daten lesen mit SELECT, das Ergebnis per fetchall() abholen und die Rolle des Cursors.

→ Grundlagen → Sicher & Speziell → Uebungen
✏️ Schreiben: INSERT / UPDATE / DELETE + commit()
import sqlite3

db = sqlite3.connect("datenbank.sqlite")
cursor = db.cursor()
sql = "INSERT INTO tblArtikel (Name, Anzahl) VALUES('Hut',14)"
cursor.execute(sql)
db.commit()   # Bestaetigt die Speicherung!
db.close()
⚠️
Merkregel: Fuer INSERT, UPDATE und DELETE ist commit() notwendig – sonst werden die Daten NICHT gespeichert.
📖 Lesen: SELECT
cursor = db.cursor()
cursor.execute("SELECT * FROM tblArtikel")
for ds in cursor:
    print(f"{ds[0]:4} {ds[1]:12} {ds[2]:5}")
💡
Hinweis: SELECT * FROM sqlite_master liefert das Schema der Datenbank (welche Tabellen es gibt).
📥 fetchall() – Ergebnis in eigene Liste
cursor.execute("SELECT * FROM tblArtikel")
data = cursor.fetchall()   # ganzes Ergebnis in Variable
db.close()                 # DB kann sofort geschlossen werden

for ds in data:
    print(f"{ds[0]:4} {ds[1]:12} {ds[2]:8.2f}")

Vorteil: Die Datenbank ist sofort schliessbar und der Fehler Unread result found wird vermieden.

🎯 Der Datenbank-Cursor (kurz erklaert)

Erst die Verbindung (Connection) ueber connect(), dann den Cursor ueber db.cursor(). Der Cursor sendet SQL (execute) und nimmt Ergebnisse entgegen.

  • Ergebnis durchlaufen mit for ds in cursor: oder – besser – data = cursor.fetchall()
  • cursor.rowcount = Anzahl betroffener Datensaetze (bei SELECT in SQLite3 nicht verfuegbar)
