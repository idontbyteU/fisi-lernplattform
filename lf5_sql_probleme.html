LF 5Probleme lösen

Schreiben — Enter — Feedback

Schreib die Abfrage in die Zeile und drücke Enter. Richtig → grüner Rahmen und Haken, falsch → kurzes rotes Wackeln (deine Eingabe bleibt stehen). Groß-/Kleinschreibung der Schlüsselwörter und zusätzliche Leerzeichen sind egal — Spalten-, Tabellennamen und Textwerte müssen exakt stimmen.

Beispiel-DB: artikel(artikelId, artikelName, preis, kategorieId) · kunde(kundeId, name) · bestellung(bestellungId, kundeId, artikelId)

1Alle Artikel unter 40 Euro — Name und Preis.

✓
Lösung anzeigen 
SELECT artikelName, preis FROM artikel WHERE preis < 40;

2Artikel, deren Name ein 'a' enthält.

✓
Lösung anzeigen 
SELECT artikelName FROM artikel WHERE artikelName LIKE '%a%';

3Alle Artikel alphabetisch nach Name.

✓
Lösung anzeigen 
SELECT artikelName FROM artikel ORDER BY artikelName ASC;

4Die zwei günstigsten Artikel — Name und Preis.

✓
Lösung anzeigen 
SELECT artikelName, preis FROM artikel ORDER BY preis ASC LIMIT 2;

5Artikel, die nicht mit B beginnen und über 35 Euro kosten.

✓
Lösung anzeigen 
SELECT artikelName, preis FROM artikel WHERE artikelName NOT LIKE 'B%' AND preis > 35;

6Welche kundeIds kommen in bestellung vor — jede nur einmal?

✓
Lösung anzeigen 
SELECT DISTINCT kundeId FROM bestellung;

7Wie viele Artikel kosten unter 100 Euro? (Spaltenname anzahl)

✓
Lösung anzeigen 
SELECT COUNT(*) AS anzahl FROM artikel WHERE preis < 100;

8Summe aller Artikelpreise (Spaltenname gesamt).

✓
Lösung anzeigen 
SELECT SUM(preis) AS gesamt FROM artikel;

9Anzahl Bestellungen pro Kunde (kundeId + Anzahl als anzahl).

✓
Lösung anzeigen 
SELECT kundeId, COUNT(*) AS anzahl FROM bestellung GROUP BY kundeId;

10Nur kundeIds mit mindestens 2 Bestellungen.

✓
Lösung anzeigen 
SELECT kundeId FROM bestellung GROUP BY kundeId HAVING COUNT(*) >= 2;

INSERT – Datensätze einfügen

11Füge den Artikel 'Kabel', 9.90 Euro, Kategorie 4 ein.

✓
Lösung anzeigen 
INSERT INTO artikel (artikelName, preis, kategorieId) VALUES ('Kabel', 9.90, 4);

12Füge den Kunden 'Tom' ein (kundeId automatisch).

✓
Lösung anzeigen 
INSERT INTO kunde (name) VALUES ('Tom');

UPDATE – Datensätze ändern

13Ändere den Preis der Tastatur auf 29.90.

✓
Lösung anzeigen 
UPDATE artikel SET preis = 29.90 WHERE artikelName = 'Tastatur';

14Verschiebe 'Windows 11' in Kategorie 1.

✓
Lösung anzeigen 
UPDATE artikel SET kategorieId = 1 WHERE artikelName = 'Windows 11';

DELETE – Datensätze löschen

15Lösche alle Bestellungen von Kunde 2.

✓
Lösung anzeigen 
DELETE FROM bestellung WHERE kundeId = 2;

16Lösche alle Artikel unter 10 Euro.

✓
Lösung anzeigen 
DELETE FROM artikel WHERE preis < 10;

JOIN – Tabellen verknüpfen

17Zeige zu jedem Artikel Name + Kategoriebezeichnung.

✓
Lösung anzeigen 
SELECT a.artikelName, k.bezeichnung FROM artikel a
INNER JOIN kategorie k ON a.kategorieId = k.kategorieId;

18Alle Kunden mit ihren Bestellungen — auch Kunden ohne.

✓
Lösung anzeigen 
SELECT k.name, b.bestellungId FROM kunde k
LEFT JOIN bestellung b ON k.kundeId = b.kundeId;

Subqueries – Unterabfragen

19Der günstigste Artikel — ohne LIMIT, mit Unterabfrage.

✓
Lösung anzeigen 
SELECT artikelName, preis FROM artikel
WHERE preis = (SELECT MIN(preis) FROM artikel);

20Welche Kunden haben noch nie bestellt? (EXISTS-Familie)

✓
Lösung anzeigen 
SELECT name FROM kunde k WHERE NOT EXISTS
(SELECT 1 FROM bestellung b WHERE b.kundeId = k.kundeId);

Funktionen – CONCAT & Datum

21Zu jedem Artikel 'Name (Preis Euro)' als Spalte info. (CONCAT)

✓
Lösung anzeigen 
SELECT CONCAT(artikelName, ' (', preis, ' Euro)') AS info
FROM artikel;

22Zeige zu jedem Kunden das aktuelle Datum als Spalte heute.

✓
Lösung anzeigen 
SELECT name, CURRENT_DATE AS heute FROM kunde;
